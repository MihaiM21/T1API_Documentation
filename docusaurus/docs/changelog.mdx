# Changelog

All notable changes to the T1API are documented here. T1API follows [Semantic Versioning](https://semver.org). Breaking changes will always be accompanied by a major version bump and at least 6 months' migration notice.

<Callout variant="info">
Subscribe to API updates via the [dashboard](https://turnonehub.com/dashboard) or watch the [GitHub repository](https://github.com/Turn-One-Organization) for release notifications.
</Callout>
