# Real-Time Data

T1API is a REST API — it does not expose a WebSocket endpoint. Real-time data is delivered by polling the analysis endpoints, which source live session data directly from `livetiming.formula1.com` via the V2 pipeline. This page explains how to use the API effectively during live sessions.

## How live data works

When a session is active, V2 endpoints call the F1 live timing server on every request before returning a response. The result is cached in MongoDB with a configurable TTL (default: 3,600 seconds). During a live session, the cache is invalidated based on session state changes to keep data fresh.
